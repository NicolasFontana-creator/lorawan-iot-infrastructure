# Resultados y alcance

[Español](README.md) · [English](README.en.md)

El informe confirma la interconexión funcional de las herramientas. Las capturas registran el estado del ensayo. No se publicaron mediciones de latencia, disponibilidad o consumo. El autor confirmó la conexión de RStudio con InfluxDB para acceder a las series almacenadas. El análisis predictivo y el manejo de mayores volúmenes de datos son posibles extensiones. No se documentaron modelos entrenados, predicciones ni validaciones estadísticas.

Las páginas 4–15 acreditan las vistas, consultas y generación de reportes. La conclusión en p. 16 se refiere a integración de software. Los paneles son evidencia histórica, sin garantía de disponibilidad actual ni medición de cobertura radioeléctrica. Para reproducir el despliegue se necesitarían flujos de Node-RED, exportaciones de dashboards, consultas y configuración saneada del acceso LoRaWAN.

Fuente: Nicolás Nahuel Fontana, *Gestión eficiente de recursos en ciudades inteligentes. Desarrollo de una plataforma IoT*, Laboratorio de Telecomunicaciones, UTN FR Paraná.
